# 📊 Jisha Enterprise Sales Analysis (SQL Project)

Data Analysis with SQL focuses on exploring, cleaning, and analyzing data using SQL queries. It includes joins, aggregations, subqueries, and window functions to uncover insights, identify trends, and support data-driven decisions using structured and relational datasets.

---

## 🗂️ Project Overview
This project focuses on analyzing sales data using SQL. The dataset, **jisha interprise.csv**, contains information about product sales, revenue, and other key business metrics. The goal is to extract meaningful insights through SQL queries — covering cleaning, transformation, and reporting.

---

## 🎯 Objectives
- Clean and prepare raw data for analysis  
- Perform exploratory data analysis (EDA) using SQL  
- Generate monthly and yearly sales trends  
- Identify top-performing products and categories  
- Calculate revenue growth and customer insights  

---

## 🧰 Tools & Technologies
- **Database:** MySQL / SQLite  
- **Language:** SQL  
- **Dataset:** jisha interprise.csv  
- **Platform:** MySQL Workbench / DBeaver / SQLite Studio
